## Deviations from the specification

Recorded here so the spec can be amended or the code brought back in line. See `docs/spec-deviations.md`.

## Waiting on things the cloud CI cannot do

- **Archive recordings**: `python/tests/cassettes/` holds what the **Archive live smoke** workflow recorded on 2026-10-28: the Gaia DR3 and PS1 DR2 schemas and smoke cones, and the 2MASS schema. Every cassette there came from a live run, and none was written by hand. They replay through the TAP adapter and the dialects in `tests/archives/test_recorded_responses.py`. That replay found PS1's `epochMean = -999` sentinel, so the `ps1-dr2` dialect 1.1.0 now leaves those objects out and counts them in the curated Parquet's `sdp.excluded_rows` metadata. Two things are still missing. The 2MASS cone timed out at IRSA on the second run, so its replay tests skip until a run records it. The smoke run does not call CDS X-Match, so DSI-009 (X-Match agreeing with the CPU reference on live answers) stays draft.
- **The DOI publisher**: the production composition root refuses publication (`NotConfigured`) until the Zenodo publisher lands later in the train.

- **The 1919 data**: no measurement or published estimate has been transcribed. Every UC-02 run so far uses synthetic bundles with a planted deflection, and the verdict is INCONCLUSIVE by design because REL-G-04 and REL-G-07 name oracles that are still `to_transcribe`. Transcription (page locator plus a second reader for every row) is human work; `sdp_relativity.transcription.bundle_from_records` turns the stored records into the run's input.
- **DGX Spark spike** (ADR-013): procedure in `docs/spike/phase0-dgx-spark.md`; must be run on the host.
- **Predeclaration sign-off**: both predeclarations are drafts; Leigh confirms regions, cuts and tolerances before `freeze()`. For UC-01 that includes the candidate thresholds now held as constants (deviation D15).
- **UC-01 benchmark catalogues**: Hunt and Reffert 2023 and Cantat-Gaudin et al. 2020 are not ingested. Every UC-01 run so far uses synthetic fields and synthetic benchmark tables (labelled as such in their Parquet metadata). Their release labels, licences and citations must be confirmed from the publications before the real tables become inputs.
