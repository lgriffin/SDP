## Deviations from the specification

Recorded here so the spec can be amended or the code brought back in line. See `docs/spec-deviations.md`.

## Waiting on things the cloud CI cannot do

- **Archive recordings**: `python/tests/cassettes/` holds what the **Archive live smoke** workflow recorded on 2026-10-28: the Gaia DR3 and PS1 DR2 schemas and smoke cones, and the 2MASS schema. Every cassette there came from a live run, and none was written by hand. They replay through the TAP adapter and the dialects in `tests/archives/test_recorded_responses.py`. That replay found PS1's `epochMean = -999` sentinel, so the `ps1-dr2` dialect 1.1.0 now leaves those objects out and counts them in the curated Parquet's `sdp.excluded_rows` metadata. Two things are still missing. The 2MASS cone timed out at IRSA on the second run, so its replay tests skip until a run records it. CDS X-Match answers for the cross-match fixture are not recorded yet, so DSI-009 (X-Match agreeing with the CPU reference on live answers) stays draft. The smoke now records them too: run **Archive live smoke** by hand, or `tools/record_live_data.py` on any machine (see `docs/live-data.md`).
- **The DOI publisher**: `ZenodoPublisher` is tested against a fake of the deposition API only. Set `SDP_ZENODO_TOKEN` (or `SDP_ZENODO_TOKEN_FILE`) and `SDP_ZENODO_CREATORS`, publish once to the Zenodo sandbox, and only then point `SDP_ZENODO_URL` at production.
- **Mutation high-water marks**: run the **mutation** workflow once with `update` ticked; it pushes the scores it measured to a `mutation/high-water-<run>` branch for review. No mark was written by hand.

- **The 1919 data**: no measurement or published estimate has been transcribed. Every UC-02 run so far uses synthetic bundles with a planted deflection, and the verdict is INCONCLUSIVE by design because REL-G-04 and REL-G-07 name oracles that are still `to_transcribe`. Transcription (a page locator for every row, then a second pass over each row against the page) is human work; SDP is single-user, so the transcriber may make that second pass; `sdp_relativity.transcription.bundle_from_records` turns the stored records into the run's input.
- **DGX Spark spike** (ADR-013): procedure in `docs/spike/phase0-dgx-spark.md`; must be run on the host. Its results pin the DCGM exporter tag (D17) and close NFR-001 by deploying the Quadlet units there.
- **First release**: v0.1.0 was tagged on 2026-10-28. Its release run failed in T9, the kernel image and Stryker on the spec harness; the fixes are in #40, and the next release run is the first to exercise them. `release-as` has been removed from `release-please-config.json`, so release-please now picks the next version from Conventional Commits. GitHub Actions must be allowed to create pull requests (repository Settings, then Actions, then General).
- **Predeclaration sign-off**: both predeclarations are drafts; Leigh confirms regions, cuts and tolerances before `freeze()`. For UC-01 that includes the candidate thresholds now held as constants (deviation D15).
- **UC-01 benchmark catalogues**: Hunt and Reffert 2023 and Cantat-Gaudin et al. 2020 are not ingested. Every UC-01 run so far uses synthetic fields and synthetic benchmark tables (labelled as such in their Parquet metadata). Their release labels, licences and citations must be confirmed from the publications before the real tables become inputs.
