# Journey: rerun Oort's 1932 measurement of the force toward the galactic plane

**Time:** about 1 minute for the arithmetic. The full run is one pass over every file of your bulk Gaia copy and one over its rvs subset, which takes tens of minutes. **Download:** nothing, if you already built the rvs subset for the [Oort 1927 journey](oort-1927.md). **Needs:** the [developer tools](install-dev-tools.md), the bulk copy from [Hunt for star clusters](discovery-search.md), and its rvs subset.

In 1932 Jan Oort weighed the Galaxy's disc near the Sun. Stars bob up and down through the plane, and the plane's gravity pulls them back. From how quickly a group of stars thins out with height, and how fast those stars move up and down, he worked out the pull K(z) at each height z. It grows in step with height for the first 200 parsecs, then stays about level. The slope near the plane gives the total density of matter around the Sun: 0.092 solar masses per cubic parsec. That is more than twice what he could count in stars, and the gap is the first measured "dark matter".

This journey checks Oort's arithmetic, then remeasures the pull with Gaia's stars. The method was fixed before any Gaia star was read, in [docs/protocols/uc05-oort-1932.md](../protocols/uc05-oort-1932.md).

## Step 1: the 1932 arithmetic (no data)

From the `python` folder of your copy:

```
uv run sdp oort1932 arithmetic
```

Each figure is recomputed from Oort's own inputs and shown beside the printed one. Examples are the constant in his formula (9), his shape factors, and the slope of his Table 14.

## Step 2: the full run

`SDP_ARTIFACT_ROOT` must point at your bulk copy. If the rvs subset is not built yet, build it first, as step 2 of the [Oort 1927 journey](oort-1927.md) explains. Then:

```
uv run sdp oort1932 run --out reports/uc05
```

It reads the rvs subset first, then the full copy, and ends with the verdict. Open `report.md` first: it sets Gaia's pull beside Oort's Table 14 and gives the local density. Add `--baseline-only` for a quick look: it runs only the baseline, and the report says that its verdict is not the protocol's.

## Step 3: export the samples for the recorded test

```
uv run sdp oort1932 export --out reports/uc05
```

This writes `density.parquet` and `velocities.parquet`: every star the run could use, from the full copy and from the rvs subset. Add `--every 10` to keep only stars whose `source_id` is a multiple of 10, if the files are too big to send. Send them back with `report.json` and `report.md`, so they can become the known-answer test, as the Oort 1927 run did.
