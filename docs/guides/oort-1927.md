# Journey: rerun Oort's 1927 detection of galactic rotation

**Time:** about 1 minute for the arithmetic. The full run is one pass over every file of your bulk Gaia copy, which takes tens of minutes. **Download:** nothing for the proper-motion method. The radial-velocity method needs the rvs subset, which downloads ESA's files once more. **Needs:** the [developer tools](install-dev-tools.md) and the bulk copy from [Hunt for star clusters](discovery-search.md).

In 1927 Jan Oort showed that the stars near the Sun share the Galaxy's rotation, and that the rotation is differential: the inner stars move faster than the outer ones. Stars ahead of and behind us along the orbit then seem to drift apart, so their radial velocities vary with galactic longitude as a double wave. He measured that wave's size, the constant A, from the radial velocities of distant stars, and used it to put the Galaxy's centre about 6,000 parsecs away.

This journey checks Oort's arithmetic, then refits his constants to Gaia's stars. The method was fixed before any Gaia star was read, in [docs/protocols/uc04-oort-1927.md](../protocols/uc04-oort-1927.md).

## Step 1: the 1927 arithmetic (no data)

From the `python` folder of your copy:

```
uv run sdp oort1927 arithmetic
```

Each figure is recomputed from Oort's own inputs and shown beside the printed one. Examples are the mean A of his Table 2 and the distance to the centre for each of his three force ratios.

## Step 2 (optional): build the radial-velocity subset

Oort's own method used radial velocities. Your bulk copy has none, so build the rvs subset once:

```
uv run sdp archive bulk --subset rvs --count 1
uv run sdp archive bulk --subset rvs --workers 4
```

It reads every ESA file again and keeps only the stars with a radial velocity. Stop it with Ctrl+C and run it again to resume. Without it, the run below skips the radial-velocity method and says how to add it.

## Step 3: the full run

`SDP_ARTIFACT_ROOT` must point at your bulk copy:

```
uv run sdp oort1927 run --out reports\uc04
```

It prints its progress through the files and ends with the verdict. Open `report.md` first. Add `--baseline-only` for a quick look: it fits only the baseline, and the report says that its verdict is not the protocol's.

## Step 4: export a sample for the recorded test

```
uv run sdp oort1927 export --out reports\uc04\oort-sample.parquet
```

This writes the stars whose `source_id` is a multiple of 100, so the same sample comes out every time. Send the file back so it can become the known-answer test, as the M13 cone did for the Einstein journey. Add `--rv` to export from the rvs subset instead.
